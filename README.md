# Minecraft Bot Dashboard

Bot autônomo de Minecraft (Mineflayer) controlado por API Node/Express, com painel React mostrando estado em tempo real e visão ao vivo do bot.

## Funcionalidades
- Patrulha, coleta de madeira, seguir jogador e defesa automática
- Painel React com vida, fome, posição, inventário e comandos
- Visão 3D ao vivo embutida no painel
- Reconexão automática

## Stack
Node.js, Express, Mineflayer, React, Vite, Docker
